# Chithambaresh S — Personal Portfolio Website

A bold, high-performance personal portfolio website for **CHITHAMBARESH S**, an **Aspiring AI/ML Engineer & Software Developer (SDE)**.

Built with **React**, **Tailwind CSS**, and **Vite**, featuring a dark-hero aesthetic with warm orange accent accents, card-based grids, interactive project architecture modals, smooth scroll anchor navigation, and responsive layouts.

---

## 🎨 Design Highlights & Tech Stack

- **Palette**: Near-black / charcoal backgrounds (`#0d0d0d`, `#111111`, `#161616`) paired with bold warm orange accents (`#E8792A`, `#F97316`).
- **Typography**: Clean sans-serif hierarchy using Inter and bold uppercase Poppins headings.
- **Frontend Core**: React 18 + Vite + Tailwind CSS.
- **Icons**: Lucide Icons.
- **Responsiveness**: Mobile drawer, tablet grid layouts, desktop multi-column designs.

## 💻 Getting Started

### 1. Development Mode
To start the live development server:
```bash
npm run dev
```

### 2. Production Build
To create an optimized production build:
```bash
npm run build
```

### 3. Local Preview
To preview the production build locally:
```bash
npm run preview
```
